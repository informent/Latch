# Security policy

Please report vulnerabilities privately to the repository owner rather than opening a public issue with exploit details. Include affected version, impact, and a reproducible description. Do not send real bot tokens, private server messages, or ticket-store files.

Latch is an early project and has not had an independent security audit. Run it only in a server where you can review channel permissions and logs. The bot token and all files under `data/` are sensitive; restrict access to them. The repository ignores these runtime JSON files by default.
